## Características

Aimeos es un paquete de comercio electrónico con todas las funciones:

* Multi proveedor, multi canal y multi almacén
* Desde un producto hasta más de 1.000.000.000 de artículos
* Extremadamente rápido, hasta 20ms
* Para soluciones SaaS de comercio electrónico multiinquilino con proveedores ilimitados
* Paquetes, vales, productos virtuales, configurables, personalizados y de eventos
* Suscripciones con pagos recurrentes
* Más de 100 pasarelas de pago
* Soporte completo RTL (frontend y backend)
* Precios por bloques/niveles listos para usar
* Extensión para precios por cliente/grupo
* Soporte de descuentos y vales
* Sistema flexible de reglas del carrito
* Backend de administración completo
* Hermoso panel de administración
* Conjuntos de datos de productos configurables
* API REST JSON basada en jsonapi.org
* API GraphQL para administración
* Estructura completamente modular
* Extremadamente configurable y extensible
* Extensión para mercados con millones de proveedores
* Totalmente optimizado para SEO, incluidos rich snippets
* Traducido a más de 30 idiomas
* Traducción de texto basada en IA
* Optimizado para smartphones y tablets
* Implementación segura y revisada
* Código fuente de alta calidad

... y [más características de Aimeos](https://aimeos.org/features)

## Versiones compatibles

Actualmente, los paquetes Aimeos Laravel **2024.10 y posteriores** son totalmente compatibles:

- Versión LTS: 2025.10+ (Laravel 10.x, 11.x y 12.x)
- Versión LTS anterior: 2024.10+ (Laravel 10.x y 11.x)

Si quieres actualizar entre versiones principales, por favor consulta la
[guía de actualización](https://aimeos.org/docs/latest/laravel/setup/#upgrade)!

## Requisitos

La distribución de tienda Aimeos requiere:
- Entorno Linux/Unix, WAMP/XAMP o MacOS
- PHP >= 8.1
- MySQL >= 5.7.8, MariaDB >= 10.2.2, PostgreSQL 9.6+, SQL Server 2019+
- Servidor web (Apache, Nginx o servidor web PHP integrado para pruebas)

Si faltan extensiones PHP requeridas, `composer` te informará sobre las dependencias
faltantes.

Si quieres actualizar entre versiones principales, por favor consulta la
[guía de actualización](https://aimeos.org/docs/latest/laravel/setup/#upgrade)!

## Base de datos

Asegúrate de haber **creado la base de datos** previamente y de haber añadido la
configuración en el archivo `.env` de tu directorio de aplicación. A veces,
el uso del archivo `.env` genera problemas y obtendrás excepciones indicando que la
conexión con la base de datos falló. En ese caso, añade también las credenciales
de la base de datos a la sección **resource/db** de tu archivo `./config/shop.php`.

Si no tienes al menos MySQL 5.7.8 o MariaDB 10.2.2 instalado, probablemente obtendrás
un error como:

```
Specified key was too long; max key length is 767 bytes
```

Para evitar este problema, elimina las tablas nuevas si se han creado y cambia la
configuración de charset/collation en `./config/database.php` a estos valores antes
de instalar Aimeos otra vez:

```php
'connections' => [
    'mysql' => [
        // ...
        'charset' => 'utf8',
        'collation' => 'utf8_unicode_ci',
        // ...
    ]
]
```

**Precaución:** Asegúrate también de que tu servidor MySQL crea tablas *InnoDB* por
defecto, ya que las tablas *MyISAM* no funcionarán y producirán un error de
restricción de clave foránea.

Si deseas usar un servidor de base de datos distinto a MySQL, consulta el artículo
sobre [servidores de base de datos compatibles](https://aimeos.org/docs/latest/infrastructure/databases/)
y su configuración específica. Están soportados:

* MySQL, MariaDB (completamente)
* PostgreSQL (completamente)
* SQL Server (completamente)

Asegúrate de usar uno de los servidores de base de datos compatibles en tu archivo
`.env`, por ejemplo:

```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=aimeos
DB_USERNAME=root
DB_PASSWORD=
```

**Precaución:** ¡La base de datos SQLite configurada por defecto **NO** está
soportada!**

## Instalación

El paquete de tienda online Aimeos Laravel es una librería basada en Composer. Se
puede instalar más fácilmente usando [Composer 2.1+](https://getcomposer.org) en el
directorio raíz de tu aplicación Laravel existente:

```
wget https://getcomposer.org/download/latest-stable/composer.phar -O composer
```

Luego, añade estas líneas al `composer.json` de la **aplicación base de Laravel**:

```json
    "prefer-stable": true,
    "minimum-stability": "dev",
    "require": {
        "aimeos/aimeos-laravel": "~2025.10",
        ...
    },
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan vendor:publish --tag=public --ansi",
            "\\Aimeos\\Shop\\Composer::join"
        ],
        ...
    }
```

Después, instala el paquete de tienda Aimeos usando:

`php composer update -W`

En el último paso, debes ejecutar estos comandos artisan para obtener una
instalación de Aimeos funcional o actualizada:

```bash
php artisan vendor:publish --tag=config --tag=public
php artisan migrate
php artisan aimeos:setup --option=setup/default/demo:1
```

En un entorno de producción o si no quieres que se instalen los datos de demo,
deja fuera la opción `--option=setup/default/demo:1`.

## Autenticación

Debes configurar uno de los kits de inicio de autenticación de Laravel. Laravel
Breeze es el más sencillo, pero también puedes usar Jetstream.

```bash
composer require laravel/breeze
php artisan breeze:install
npm install && npm run build # si no se ejecuta automáticamente con el comando anterior
```

Laravel Breeze te hará algunas preguntas; la más importante es el tipo de stack que
deseas usar. Selecciona “Blade” (es la forma más sencilla) y usa los valores
predeterminados para las demás opciones.

También añade una ruta para `/profile` en `./routes/web.php` que puede sobrescribir
la ruta `aimeos_shop_account`. Para evitar una excepción por falta de la ruta
`aimeos_shop_account`, cambia la URL de estas líneas en el archivo `./routes/web.php`
de `/profile` a `/profile/me`:

```php
Route::middleware('auth')->group(function () {
    Route::get('/profile/me', [ProfileController::class, 'edit'])->name('profile.edit');
    Route::patch('/profile/me', [ProfileController::class, 'update'])->name('profile.update');
    Route::delete('/profile/me', [ProfileController::class, 'destroy'])->name('profile.destroy');
});
```

Para más información, sigue la documentación de Laravel:
* [Laravel 12.x](https://laravel.com/docs/12.x/authentication)
* [Laravel 11.x](https://laravel.com/docs/11.x/authentication)
* [Laravel 10.x](https://laravel.com/docs/10.x/authentication)

### Configurar autenticación

Como último paso, necesitas extender el método `boot()` de tu clase
`App\Providers\AppServiceProvider` y añadir estas líneas para definir cómo se verifica
la autorización de “admin” en `app/Providers/AppServiceProvider.php`:

```php
    public function boot()
    {
        // Keep the lines before

        \Illuminate\Support\Facades\Gate::define('admin', function($user, $class, $roles) {
            if( isset( $user->superuser ) && $user->superuser ) {
                return true;
            }
            return app( '\Aimeos\Shop\Base\Support' )->checkUserGroup( $user, $roles );
        });
    }
```

### Crear cuenta

Verifica que tu configuración de autenticación funcione antes de continuar. Crea una
cuenta de administrador para tu aplicación Laravel para que puedas iniciar sesión en
la interfaz de administración de Aimeos:

```bash
php artisan aimeos:account --super <email>
```

La dirección de correo electrónico es el nombre de usuario para el inicio de sesión y
la cuenta funcionará también para el frontend. Para proteger la nueva cuenta, el
comando te pedirá una contraseña. El mismo comando puede crear cuentas limitadas
usando `--admin`, `--editor` o `--api` en lugar de `--super` (acceso a todo).

## Configuración

Para referenciar las imágenes correctamente, debes adaptar tu archivo `.env` y
establecer `APP_URL` a tu URL real, por ejemplo:

```
APP_URL=http://127.0.0.1:8000
```

**Precaución:** Asegúrate de que Laravel use el driver de sesión `file` en tu archivo
`.env`. De lo contrario, el contenido del carrito no se guardará correctamente.

```
SESSION_DRIVER=file
```

Si tu directorio `./public` no es escribible por tu servidor web, debes crear estos
directorios:

```
mkdir public/aimeos public/vendor
chmod 777 public/aimeos public/vendor
```

En un entorno de producción, deberías ser más específico con los permisos otorgados.

## Prueba

Luego deberías poder acceder a la página de listado del catálogo desde tu navegador.
Para un inicio rápido, puedes usar el servidor web integrado. Simplemente ejecuta este
comando desde el directorio raíz de tu aplicación:

```
php artisan serve
```

### Frontend

Apunta tu navegador a la página de listado de la tienda usando:

http://127.0.0.1:8000/shop/search

**Nota:** Integrar el paquete Aimeos añade algunas rutas como `/shop` o `/admin`
a tu instalación Laravel, pero la **página de inicio permanece intacta**. Si quieres
añadir Aimeos también a la página de inicio, reemplaza la ruta para `/` en
`./routes/web.php` por esta línea:

```php
Route::group(['middleware' => ['web']], function () {
    Route::get('/', '\Aimeos\Shop\Controller\CatalogController@homeAction')->name('aimeos_home');
});
```

Para configuraciones multi-proveedor, lee el artículo sobre [tiendas múltiples](https://aimeos.org/docs/latest/laravel/customize/#multiple-shops).

Esto mostrará el componente de inicio del catálogo Aimeos en la página de inicio y
tendrás una bonita página principal de tienda que se verá así:

[![Frontend de Aimeos](https://aimeos.org/fileadmin/aimeos.org/images/aimeos-frontend.jpg?2021.07)](http://127.0.0.1:8000/)

### Backend

Si todavía tienes iniciado el servidor PHP interno (`php artisan serve`), ahora
debes abrir esta URL en tu navegador:

http://127.0.0.1:8000/admin

Introduce la dirección de correo electrónico y la contraseña del usuario recién creado
y pulsa el botón "Login". Si no te redirige a la interfaz de administración (eso depende del
código de autenticación que hayas creado según la documentación de Laravel), vuelve a
abrir la URL `/admin` en el navegador.

**Precaución:** Asegúrate de no estar ya conectado como un usuario que no sea admin.
En ese caso, el inicio de sesión no funcionará porque Laravel requiere que cierres la
sesión primero.

[![Backend de Aimeos](https://aimeos.org/fileadmin/aimeos.org/images/aimeos-backend.png)](http://127.0.0.1:8000/admin)

## Consejos

Para simplificar el desarrollo, deberías desactivar la caché de contenido.
Puedes hacer esto en el archivo `config/shop.php` de tu aplicación Laravel añadiendo
estas líneas al final:

```php
    'madmin' => [
        'cache' => [
            'manager' => [
                'name' => 'None',
            ],
        ],
    ],
```
