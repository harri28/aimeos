Cómo funciona Aimeos

Aimeos no es un plugin que se activa: es un conjunto de paquetes de Composer que se instalan dentro de una aplicación Laravel normal y le añaden todo lo necesario para vender — catálogo, precios, carrito, checkout, panel de administración. Este mapa sigue el camino que recorre una petición, de principio a fin.

Laravel (el anfitrión) Aimeos (el motor de tienda) Base de datos

02

Tres formas de entrar al mismo motor

Aimeos no es solo la tienda pública. El mismo catálogo y las mismas reglas de negocio se exponen por tres puertas distintas, cada una para una audiencia distinta.

Tienda

ai-client-html

Lo que ve el cliente: inicio, categorías, ficha de producto, carrito, checkout, cuenta.

  • Plantillas en .blade.php + PHP
  • Ruta raíz: aimeos_home
  • Personalizada hoy: logo, idioma, moneda

Panel admin

ai-admin-jqadm

Interfaz Vue.js para gestionar productos, pedidos, clientes, precios — donde entras tú.

  • Ruta: /admin → jqadm
  • Protegida por Gate::define('admin')
  • Personalizada hoy: logo, checkbox "todos"

APIs

jsonapi · graphql

Para que otras apps (una app móvil, un sistema externo) hablen con la tienda sin pasar por HTML.

  • No la estamos usando activamente todavía
  • Mismo motor de datos que la tienda y el admin
03

Cinco palabras que verás en todos lados

Con esto se entiende el 80% de la configuración y de la base de datos de Aimeos.

Site (sitio)
Aimeos es multi-tienda por diseño. Todo registro de la base de datos lleva un siteid. Nosotros usamos uno solo: default.
Locale (idioma + moneda)
Cada combinación activa de idioma/moneda es una fila en mshop_locale. La nuestra: es / PEN, posición 0.
Domain (dominio)
Cada "tipo de cosa" del negocio: product, catalog, price, order, service. Cada uno tiene su propio manager y sus propias tablas.
Manager
La clase que sabe leer y escribir un dominio en la base de datos — el único camino "oficial" para tocar los datos, en vez de hacer SQL a mano.
Item / List
Un producto es un Item. Sus relaciones (precio, imagen, texto, categoría) se conectan a través de tablas *_list, no columnas sueltas.
Extensión (ext/)
La forma soportada de sobrescribir plantillas de Aimeos sin tocar vendor/. Así hicimos el logo y el checkbox "seleccionar todos".
